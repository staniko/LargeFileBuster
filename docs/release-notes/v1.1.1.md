**LargeFileBuster** is an interactive disk-space explorer for Windows: it scans your drives, ranks every folder and file by size, keeps the results in a local SQLite database and lets you jump straight to the biggest space hogs. The [README](https://github.com/staniko/LargeFileBuster#readme) shows what it can do.

Version 1.1.1 is a security release. It adds no features. It hardens the app and its release pipeline and moves to a current, supported Electron.

## Download

Grab the `LargeFileBuster-Setup-1.1.1.exe` installer from the assets below (Windows x64, NSIS installer; you can choose the install directory). Installing over an older version keeps your scan results.

The installer is not code-signed, so Windows SmartScreen may warn on first start. To verify your download, compare its SHA-256 (`Get-FileHash .\LargeFileBuster-Setup-1.1.1.exe` in PowerShell) with the digest GitHub shows next to the file below.

## What's new in 1.1.1

### Security
- Electron 35 → 45. Electron 35 no longer receives security fixes.
- The window can only show the app's own UI: it is served from a private `app://` origin with a strict Content-Security-Policy, cannot navigate or open pop-ups, has no network access, and all permission requests are denied.
- The main process answers only the app's own window and validates every request. Before, a malformed request could reset the scan database.
- An installed app can no longer be switched into development mode with `NODE_ENV=development`.
- The SQLite WebAssembly file is loaded from the app's own resources only, no longer from the current working directory.
- Release builds ignore `ELECTRON_RUN_AS_NODE`, `NODE_OPTIONS` and `--inspect`, and check the integrity of the app code on start (Electron fuses, ASAR integrity).
- Opening a folder no longer follows symbolic links and junctions.

### Build & release
- The job that builds and tests the app has a read-only token. A separate job publishes the release, after checking the installer against its recorded checksum.
- GitHub Actions are pinned to commit hashes, and Dependabot keeps them and the npm packages current.
- 13 new security regression tests, and every build starts the packaged app to check its protections.

### Good to know
- The installer grows from 79 MB to about 113 MB. That is the newer Electron runtime, not the app.
- Developer Tools stay available in the View menu.

[SECURITY.md](https://github.com/staniko/LargeFileBuster/blob/main/SECURITY.md) describes the protection model and its known limitations, and how to report a vulnerability.
