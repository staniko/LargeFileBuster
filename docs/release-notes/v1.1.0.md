First public release of **LargeFileBuster**, an interactive disk-space explorer for Windows. It scans your drives, ranks every folder and file by size, keeps the results in a local SQLite database and lets you jump straight to the biggest space hogs.

## Download

Grab the `LargeFileBuster-Setup-1.1.0.exe` installer from the assets below (Windows x64, NSIS installer; you can choose the install directory).

## Features

- Drive and folder browser with breadcrumbs, back button and double-click drill-down
- Deep (recursive) and shallow (single-level) scanning with live progress
- Scan results persisted in a local `lfb.sqlite` database (sql.js / WebAssembly)
- Top-lists sidebar ranking the largest folders and files, with sortable columns
- Context menu: "Continue deep scan…" with a date picker to skip recently scanned subtrees, and "Open in Explorer"
- Reset database from the File menu

## What's new since the initial version

### Performance
- Fewer database persists during scans (every 50k instead of 5k items) and GC enabled during scans
- Virtualized list rendering (react-window) and CSS-only row hover instead of inline handlers

### Fixes
- Breadcrumb navigation no longer pushes entries onto the back history
- TypeScript build errors around list item types resolved

### Security & maintenance
- Upgraded sql.js 1.9 → 1.14, TypeScript 5.9, ESLint 9, @electron-toolkit packages
- Fixed vulnerable transitive dependency (ajv 6.12.6 → 6.14.0)

### Build & CI
- GitHub Actions pipeline: typecheck, lint, build, Playwright tests and Windows installer packaging
- Installer now shows the license (EUPL-1.2) and NOTICE
- New Playwright performance and stress tests (Temp folder navigation, full C: drive scan with navigation)
